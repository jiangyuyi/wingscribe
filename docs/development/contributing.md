# 开发、测试与文档维护

协作约定以根目录 [AGENTS.md](../../AGENTS.md) 为准。先按 [环境说明](environment.md) 安装锁定依赖并激活对应 Python 环境，在仓库根目录运行：

```powershell
python -m pytest
python -m pytest tests/test_path_parser.py -v
```

`pytest.ini` 配置严格标记和 `src` 分支覆盖率。行为变更需补相应测试；不要把历史测试数量写成当前验证结果。安装器变更另外执行 [构建说明](../../installer/README.md) 与 [发布验收](release-checklist.md)。

## 文档变更规则

1. 使用说明对照真实入口、参数和配置读取位置，不从旧 AI 回复复制“已支持”结论。
2. 当前问题只维护 [项目状态](status.md)，已完成计划不再作为活动上下文。
3. 新实验记录包含日期、数据/候选集标识、方法、指标和限制；生产接入状态明确写出。
4. 移动文档时更新仓库链接、发布工作流中的文档链接和文档索引。
5. 历史证据归档并加提示；已替代的一次性命令和重复草案可删除，在迁移记录说明去向。
6. 原始对话和本地资料先确认归属；不要把里面的私人路径、账号信息或未经验证的建议扩散到现行指南。

本轮文档整理使用本地文件工具和源码核查即可，无需安装额外 skill 或引入文档生成依赖。
