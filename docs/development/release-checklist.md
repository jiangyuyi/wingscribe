# Windows CPU/GPU 发布验收清单

> 适用安装包：`WingScribe-Setup-<CPU或GPU>-<版本>.exe`，GPU 还包含同版本全部 `-N.bin` 分卷及摘要清单
> 验收日期：`____-__-__`
> 验收环境（Windows 版本/机器）：`________________`

此表是每次发布需要填写的模板，不是已通过证明。CPU/GPU 各填写一次，在没有开发环境的干净 Windows 机器验收。

构建步骤见 [安装器说明](../../installer/README.md)。

## 1. 安装与卸载
- [ ] 安装完成后目录存在：`{app}\python`、`{app}\src`、`{app}\scripts`
- [ ] 开始菜单快捷方式可启动（如安装时启用）
- [ ] 桌面快捷方式可启动（如安装时启用）
- [ ] 卸载移除程序文件，但保留运行后产生的配置、密钥、数据库、照片和备份；前后逐文件 SHA-256 一致
- [ ] 同代跨版本升级保留上述用户数据；记录升级前后版本和卸载结果
- [ ] 旧卸载日志缺少安全代际标记时拒绝覆盖、文件不变；不执行真实旧卸载器

## 2. 启动与页面可用性
- [ ] 通过快捷方式或 `scripts\start_web.bat` 能正常启动服务
- [ ] 可打开主页（默认 `http://127.0.0.1:8000`）
- [ ] 页面样式正常，无裸 HTML/错乱布局
- [ ] 浏览器 Network 中以下资源返回 `200`：
- [ ] `/lib/css/bootstrap.min.css`
- [ ] `/lib/js/bootstrap.bundle.min.js`
- [ ] `/lib/favicon.ico`

## 3. 配置功能
- [ ] 设置页修改关键路径并保存成功
- [ ] 重启服务后配置保持生效
- [ ] 输入无效路径时有明确提示，不导致服务崩溃
- [ ] 缺少配置进入设置页；错误配置不被自动覆盖，保存后重启生效

## 4. 核心流程冒烟
- [ ] 用小样本目录触发一次处理流程
- [ ] 任务可启动、日志持续输出、任务能正常结束
- [ ] 数据库正常创建或更新（如 `data\db\wingscribe.db`）
- [ ] 输出目录产生预期结果文件
- [ ] 用照片副本验证 AI 候选、人工校对、重命名及元数据写回
- [ ] 记录模型首次下载和离线缓存复用结果
- [ ] 选片历史、主体预览和人工标记刷新后保留；在副本上预览拒绝清单→隔离→恢复，原路径及哈希恢复
- [ ] NAS 断连/超时后报告来源不可用；历史记录不误删，重连后可重新扫描（记录真实 SMB 与故障注入的区别）

## 5. 稳定性与回归
- [ ] 连续启动/停止服务 3 次均成功
- [ ] 页面刷新与主要页面切换无 `500` 错误
- [ ] 空目录/无数据等边界输入不崩溃

## GPU 专项（GPU 包填写，CPU 包标记不适用）
- [ ] 记录 GPU 型号和 NVIDIA 驱动版本，`nvidia-smi` 可用
- [ ] 内置 Python 中 `torch.cuda.is_available()` 为 `True`
- [ ] 无 CUDA 运行库缺失错误，实际推理有 GPU 使用记录
- [ ] 目标 RTX 50 系列设备验证所打包 CUDA/PyTorch 的架构兼容性

## 6. 发布记录
- [ ] 记录安装包文件名与版本
- [ ] 编译成功后生成并校验 `.sha256.json`，记录 EXE 与每个分卷的大小及 `SHA256`
- [ ] 下载 CI/Release 附件后再次校验，GPU EXE 与全部分卷位于同一目录
- [ ] 无个人配置、照片、密钥、实验缓存进入载荷；固定工具来源证据已补齐
- [ ] 记录本机验证与干净 Windows 验证的区别，未验证项不标通过
- [ ] 记录验收结论（通过/阻塞）
- [ ] 若失败：记录复现步骤、关键日志、截图

## 7. 验收结论
- [ ] 通过，可发布
- [ ] 不通过，阻塞项已记录并反馈
