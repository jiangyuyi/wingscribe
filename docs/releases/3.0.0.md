# WingScribe 3.0.0

3.0.0 为 Windows 本地鸟类摄影工作流加入了 JPEG 连拍选片。打开相册中的选片页，可以按拍摄时间自动分组，在每组里查看最多三张清晰度推荐，也可以切换为候选模式自行比较。标为拒绝的照片会先列出预览，经确认后移入同一来源下的隔离目录，之后可以恢复。

- **识别与归档**。默认示例采用 BioCLIP 2，新增数据库使用 AviList v2025b 名录。原片逐项登记，重复扫描复用已有结果，共享目录暂时失联时保留历史记录。
- **安装与配置**。Windows 安装包内置 Python 并检查 VC++ x64 运行库。首次启动可在本机设置页选择来源与输出目录，保存后重启服务。
- **硬件选择**。CPU 版下载 `WingScribe-Setup-CPU-3.0.0.exe`。NVIDIA GPU 版下载 `WingScribe-Setup-GPU-3.0.0.exe` 和所有同版本 `-N.bin` 分卷，放在同一目录后启动 EXE。GPU 包使用 CUDA 12.8 版 PyTorch。首次使用本地物种识别前需准备模型权重。

**从 2.3.1 升级，请先备份，再安装到新目录。** 旧格式安装器的卸载程序可能清理安装目录中的数据。安装、名录迁移及回退步骤见[旧版升级指南](https://github.com/jiangyuyi/wingscribe/blob/v3.0.0/docs/user/upgrade-3.md)。

选片以鸟体清晰度作为参考，相近画面可人工决定。当前选片面向 JPEG。人工校对会尝试更新原图元数据，首次使用建议选照片副本。详细操作见[安装说明](https://github.com/jiangyuyi/wingscribe/blob/v3.0.0/docs/user/getting-started.md)和[选片指南](https://github.com/jiangyuyi/wingscribe/blob/v3.0.0/docs/user/culling.md)。
