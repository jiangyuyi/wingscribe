# WingScribe 3.0.1

3.0.1 改善首次配置、模型准备和物种校对的反馈。

- 安装目录页提前提示可写位置。受保护或不可写的路径会在当前页显示说明，保留输入供修改或浏览重选。
- 数据库选择器修复初始路径为空时的错误，支持选择已有文件或新文件。首次配置的基础设置预填用户本机数据目录下的数据库路径，卸载后保留。已有配置继续使用原数据库。
- BioCLIP2 自动下载固定模型版本，国内镜像直连，支持断点续传并校验完整大小与 SHA-256。下载期间显示进度，失败时保留排查信息。
- 从安装快捷方式启动后，等待本次服务就绪再自动打开浏览器。未完成配置进入设置页，配置有效进入首页。
- 物种校对确认后显示处理中遮罩，阻止重复提交。保存成功后关闭对话框并刷新，失败时显示提示并恢复操作。
- README 提供中英文入口，新增英文使用手册。

## 安装与升级

CPU 版下载 `WingScribe-Setup-CPU-3.0.1.exe`。NVIDIA GPU 版同时下载 `WingScribe-Setup-GPU-3.0.1.exe` 及所有同版本 `-N.bin` 分卷，保持名称并放在同一目录。可按随包 `.sha256.json` 核对大小和 SHA-256。

从 3.0.0 升级前，先停止扫描并关闭服务，备份配置及数据库，再安装相同硬件版本到原目录。已有数据库位置保持不变。新安装默认使用 `%LOCALAPPDATA%\WingScribe\data\wingscribe.db`。安装目录应对当前账户可写，因为设置和模型缓存仍保存在安装目录。

从 2.3.1 或更早版本升级，请先备份，再安装到新目录，详见[旧版升级指南](https://github.com/jiangyuyi/wingscribe/blob/v3.0.1/docs/user/upgrade-3.md)。人工物种校对会尝试更新原图元数据，首次使用建议选照片副本。BioCLIP2 权重在首次识别时准备，首次编码物种名称可能需要数分钟。
