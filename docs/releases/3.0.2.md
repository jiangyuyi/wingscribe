# WingScribe 3.0.2

- 文件夹模式支持父子勾选联动。递归选择父目录后，展开的子目录会自动勾选；取消某个子目录时父目录显示半选，也可以在排除的目录中重新选中更深一层。展开时才加载子目录，扫描会跳过排除的分支。
- 修复批量扫描中目录和进度总数突然变化的问题。任务先完成所选目录的统计，再使用固定总数显示进度。
- 全球名录升级至 AviList v2026（11,172 种），恢复中国候选范围（1,539 种）。自动模式在地点命中国外词典时使用全球范围，其余使用中国范围；也可手动指定。旧识别结果和人工校对不会自动重算。

## Windows 安装与升级

- CPU 版下载 `WingScribe-Setup-CPU-3.0.2.exe`。NVIDIA GPU 版下载 `WingScribe-Setup-GPU-3.0.2.exe` 和同版本的所有 `-N.bin` 分卷，保持原名并放在同一目录。两种版本均提供 `.sha256.json` 供核对。
- 从 3.0.x 升级前，停止任务并关闭应用，备份配置与数据库，再安装同一硬件版本。新数据库使用 AviList v2026。已使用 v2025b 的数据库需按[名录迁移说明](https://github.com/jiangyuyi/wingscribe/blob/v3.0.2/docs/user/taxonomy.md#迁移与回退)显式升级，才能使用新的中国范围；如果配置显式指向旧 CSV，迁移后也需改为 v2026 CSV。
- 从 2.3.1 或更早版本升级，请先备份并安装到新目录，见[旧版升级指南](https://github.com/jiangyuyi/wingscribe/blob/v3.0.2/docs/user/upgrade-3.md)。

全球分类来自 [AviList Core Team，v2026](https://www.avilist.org/checklist/v2026/)，采用 CC BY 4.0，项目筛选物种级条目并附加中文显示别名。中国范围来自 Denis Lepage / Birds Canada 维护的 Avibase 地域清单，详见[来源与范围](https://github.com/jiangyuyi/wingscribe/blob/v3.0.2/docs/research/china-regional-capture-2026-11-04.md)。项目的 MIT 许可不授予第三方资料的权利。

## English

Folder mode now supports inherited selection, a mixed state for partial selection, and subtree exclusions. Scans keep a fixed total once enumeration is complete. The global catalogue is now AviList v2026 (11,172 species), and China filtering is restored (1,539 species). Existing labels and manual corrections are preserved.

Download the single CPU EXE, or the GPU EXE and every matching BIN part. Verify using the supplied SHA-256 manifest. For a 3.0.x upgrade, stop WingScribe and back up your configuration and database first. Existing v2025b databases require an explicit migration before the updated China scope can be used. See the [English guide](https://github.com/jiangyuyi/wingscribe/blob/v3.0.2/docs/en/guide.md#species-catalogue-and-migration).
