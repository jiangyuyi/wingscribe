# 选片模式实施计划（2026-10-21，用户确认）

## 契约

- 稳妥推荐 `safe`（默认）：沿用原尺寸保护，最多推荐 3 张。
- 辅助比较 `assist`：展示可评分成员的相对排序，尺寸差异保留警告，推荐集合始终为空。
- 宽松推荐 `relaxed`：允许跨过尺寸保护、最多推荐 3 张，明确提示实验性、需复核。只豁免组内尺寸差异，不豁免缺框、噪声、曝光或小主体等无法评分状态。
- 三种模式不修改评分值、近似并列、人工最佳集合、原片或删除状态。模式版本与实际模式随结果记录。
- 本批在现有离线比较页实现页面全局默认和单组覆盖；单组可恢复跟随全局。全局默认初始为 safe，切换不重置人工勾选。这里是本页默认，不冒充已接入生产应用全局设置。
- 页面导出包含全局默认、单组覆盖和实际模式，导入校验后原子恢复；旧标签按 safe 解释。评分评估必须使用导出时的实际模式，辅助比较不计作有自动推荐。

## 执行顺序

1. 增加独立模式计算接口，保持原 `rank_group` 默认和旧报告不变，覆盖三模式、缺结果、并列与非法模式测试。
2. 报告生成器保存三模式结果，旧报告渲染时可从已有证据生成；接入离线页全局/单组控件，默认仍隐藏算法结果。
3. 导入导出保留人工标注并记录模式；评估记录各模式使用数量，不能混淆稳妥与宽松结果。
4. 跑相关 Python / JS 测试，用第三轮副本生成独立体验页；不覆盖此前盲评报告和标注。真实浏览器交互尚需验证时如实标明。
5. 记录结果并提交。生产任务、持久化全局配置与正式选片界面的接入仍随 B6 分批推进，不在本批宣称完成。
