# JPEG 选片

从相册导航进入“选片”。此功能比较连续拍摄组内的主体清晰度，建议最多 3 张；评分仍属实验，排序不等于确认合焦。当前只支持 JPEG，RAW 暂不支持。

## 分析与重跑

1. 选择设置中已启用的照片来源；可输入来源内子目录，留空会递归处理整个来源。NAS 来源较大时建议先指定一个拍摄目录。
2. 设置相邻间隔和最长组跨度，点击“开始选片”。5 秒/30 秒是实验起点，可按拍摄情况调整。
3. 完成后在“已保存的分析”选择任务并打开结果。部分失败或停止的报告会提示不完整，不能当作全部照片已处理。

“停止任务”等待当前照片完成；关闭浏览器不停止任务。重新发起分析会建立新的任务和快照，复用版本、完整文件哈希及分析设置均匹配的缓存。缓存命中仍需读取和解码照片，因此 NAS 仍可能耗时。文件、模型或评分版本变更后重新计算。

首次启动选片或保存默认模式时会初始化选片表，已有库需迁移时先在数据库旁的 `backups/` 备份。无需另外填写模型或数据库路径，沿用当前配置；模型必须已存在本地。

## 查看和选择

- **稳妥推荐**：默认模式。主体尺度差异过大时暂不推荐，交由人工查看。
- **辅助比较**：显示候选顺序和风险提示，不自动推荐。
- **宽松推荐（实验）**：允许尺度差异条件下给出最多 3 张建议，须人工复核。

全局默认影响“跟随默认”的组；单组模式可单独覆盖。切换模式不修改人工决定。

展开“并排比较主体原像素”可选择两张照片，以 50%、100% 或 200% 比较。100% 为原像素，左右分别滚动定位；没有实现自动鸟眼对齐。无有效主体的照片仍可查看整图，但不能查看主体裁切。

每张照片可保存“保留／待定／拒绝”和备注。“拒绝”只是数据库标记，不移动或删除任何照片。人工标记按原片版本保存，重跑同一版本后仍保留；文件变化后的新版本不继承旧判断。未保存的编辑离开页面时会提示。

单独点击“预览拒绝原片清单”并确认后，才执行下面的可恢复隔离。预览时会核验来源范围和完整哈希，原片变化则提示重新分析。

## 可恢复隔离（Windows）

1. 先保存人工标记，打开需要处理的分析结果，点击“预览拒绝原片清单”。只列入当前结果中明确标为“拒绝”的 JPEG；算法未推荐并不代表拒绝。
2. 核对原路径、目标路径和数量，再点“确认隔离上述原片”。目标为同一照片来源下的 `.wingscribe-quarantine/<操作编号>/`，保留来源内相对目录。任何预览冲突须先解决；预览后文件或标记变化时会拒绝执行。
3. 查看逐项结果。整批可能部分成功，失败不会撤销已成功项；“隔离中／待核对”有具体错误，可在解决文件锁定或来源断开后点击“核对并重试未完成隔离”。双方都有文件、均缺失或内容变化时不会猜测删除。
4. 从“隔离历史”点“预览恢复清单”，核对后确认恢复到原路径。同名文件存在时禁止覆盖，须先处理冲突。历史保留所有尚未恢复的操作及最近 50 条记录。

首次执行会在数据库旁 `backups/` 备份并创建隔离操作记录。请保留数据库和隔离目录，两者共同支持恢复；不提供永久删除或清空隔离区。关闭页面后操作不会因此撤销；重新打开可查看历史，重试不会重复移动已完成项。

隔离区不参与后续选片或归档扫描。隔离后原路径暂不能显示或重新评分，恢复后重新打开结果即可。原片版本、人工标记及已生成的归档副本保留，不会随隔离自动删除。若来源配置被禁用，先恢复该来源配置再操作。

已用本机临时图片验证中断、重试与恢复；真实 NAS 断线仍待实机验收。请勿在移动期间用其他软件改写同一原片。RAW 暂不支持。


## 调整分组与历史版本

- **拆组**：在一组中勾选要拆出的照片，再点“将所选照片拆为新组”。至少选一张，并保留至少一张在原组；所选和其余照片分别成为新组。
- **合组**：勾选至少两个组的“参与合并”，再点“合并所选组”。允许人工跨自动分组边界合并，但主体尺度风险提示仍然有效。
- 调整成功后直接打开新版本。原报告不变，不重新检测或评分，人工保留/待定/拒绝及备注继续保留。拆组继承原组模式；合组的来源模式不一致时改为跟随默认。
- “分组历史版本”显示原分析和每次拆并的父版本。“查看上一版本”只打开父版本；不会删除新版本，也不会回滚人工标记。在旧版本上继续调整会产生另一分支。
- 重新打开分析时先显示原始分组，可再从历史选择修订。存在未保存人工编辑时，须先保存才能调整或切换，避免丢失编辑。

修订页面的缓存/计算数量属于原始分析，本次分组调整没有运行模型。此阶段仍未实现自动跨重新分析任务沿用手工分组。


## 改选评分主体

展开照片下的“查看／改选评分主体”，预览图按检测顺序编号：黄色是待选框，蓝色是其他候选。选择主体后点击“应用主体并重新评分”才会保存；选择“自动选择最大主体”并应用可恢复自动规则。

改选只重新读取和评分该照片，不重跑检测、不改变自动结果缓存。结果保存为新的历史版本，原版本、其他照片和人工标记保留。当前仅支持已有检测框，无框时不能改选，不支持手绘框。文件内容已变化或评分算法不兼容时须重新分析。重新运行自动分析不会自动沿用手选主体。
