# 从 WingScribe 2.3.1 升级到 3.0.0

1. 在旧版管理页停止扫描，等待正在处理的照片完成，然后关闭 Web 服务及其他访问同一数据库的程序。记下设置中的来源、归档和 SQLite 数据库的实际位置。
2. 把配置目录（包括本机私有的 `settings.yaml` 和 `secrets.yaml`）、关闭应用后的数据库目录及其备份复制到安装目录以外。确认照片来源和归档有独立备份，尤其是放在旧安装目录里的照片。如果使用 NAS，将数据库备份放在本机。保留旧安装，待新版验证通过后再处理旧环境。
3. 选择 CPU 或 NVIDIA GPU 包，安装到新的空目录。提示缺少 VC++ x64 时，按提示完成微软运行库安装，关闭其完成窗口后继续。若提示重启，保存工作并重启 Windows，再运行安装器。遇到旧安装目录保护提示时，返回并选择新目录。
4. 从新快捷方式启动，打开 `http://127.0.0.1:8000/settings`。希望重新整理照片时，选用新的本地数据库和新的输出目录。先选择少量 JPEG 副本作为来源，保存并重启，验证识别、归档及选片后再添加主照片目录。
5. 希望保留已有标签时，先对旧数据库的**副本**做名录迁移预览并检查报告，再决定是否应用。已有非空库需要显式迁移。保留旧标签和迁移备份，有歧义的物种记录留待人工复核。具体命令见[名录迁移与回退](taxonomy.md)。

需要回退时，先关闭新版，用旧版及升级前的配置、数据库备份恢复工作。保留新版输出供核对，避免两个版本同时写入同一数据库或输出目录。
